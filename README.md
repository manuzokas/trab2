adicionar um usuario: http://localhost:3000/users/addUser
atualizar um usuario: http://localhost:3000/users/updateUser/(id)
deletar um usuario: http://localhost:3000/users/deleteUser/(id)
ver a lista de usuarios completa: http://localhost:3000/users/list
ver um usuario em especifico: http://localhost:3000/users/(id)
